> This guide will help you understand how to integrate popular CSS frameworks with your CampsiteJS projects. We'll cover the basics of using the default framework, Tailwind CSS, within your static site.

### To get started with CSS frameworks in CampsiteJS, choose one of the following options:
- **[Bootstrap Integration Guide](/docs/css-frameworks/bootstrap)**: Learn how to set up and use Bootstrap in your CampsiteJS project.
- **[Foundation Integration Guide](/docs/css-frameworks/foundation)**: Discover how to integrate Foundation with your CampsiteJS site.
- **[Tailwind CSS Integration Guide](/docs/css-frameworks/tailwindcss)**: Follow this guide to implement Tailwind CSS in your CampsiteJS project.
- **[Bulma Integration Guide](/docs/css-frameworks/bulma)**: Instructions on how to use Bulma with CampsiteJS.

Each guide provides step-by-step instructions to help you seamlessly incorporate the chosen CSS framework into your static site, enhancing its design and responsiveness.
